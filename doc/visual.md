# Fluid Signature 视觉方向

## 视觉承诺

不是在字上叠一层液体滤镜，而是让名字真正成为流场里的固体记忆：墨迹绕着字形
聚集、被手指拉扯，又逐渐回到姓名轮廓。

## 原作基线

`?baseline=1` 使用原作 `fluid` 文本、Verdana 80px、七个原始 shader、原始
自动指针轨迹和颜色参数，隐藏标题、署名、引导与结算。

## 视觉系统

- 背景：温白 `#fff8fb`；文字与线条为墨黑紫 `#180815`；颜料使用原作洋红。
- 标题：Didot/Bodoni 两行高对比衬线，位于 guest shell 下方安全区。
- 辅助文字：9–10px 大写无衬线，字距 0.15–0.22em。
- 交互反馈：只使用流体本身、统一幽灵手指和短结算文字。
- 响应式：长用户名自动缩小纹理字号，底部姓名限制 42vw 并截断。

## 反模式

禁止液态玻璃卡片、霓虹渐变按钮、常驻操作说明、输入框、GUI 参数面板、Emoji、
手机外框、额外粒子与遮住姓名的大片标题。

## 动效与无障碍

流体持续运动；标题与署名固定不漂浮。减少动态偏好时隐藏幽灵手指并缩短结算过渡。
触控区域全屏，使用 Pointer Events 和 `touch-action:none`。
